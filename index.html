PROJECT 01 / 05

QCU ITSO System

Solo Full-Stack Developer · Innovation & Technology Support Office, QCU

An internal platform for managing intellectual property records — Copyright, Patent, Trademark, Utility Model, and Industrial Design — for a university research office that had been tracking everything manually.

Built completely solo: interviewed the office staff to map their real workflow, prototyped in Figma, then built the full stack with Tailwind CSS, JavaScript, and Node.js — including database schemas and permission-based access controls.

PROJECT 02 / 05

Pharmacy Management System

System Analyst & Lead UI/UX Designer

A medicine stock monitoring and dispensing system built to keep fast-moving inventory accurate under pressure — the counter couldn't afford slow lookups or manual miscounts.

Mapped the real workflow first with data flow diagrams and use cases, then designed an interface tuned for speed: fewer clicks to log a dispense, stock levels always visible.

UI/UX Designer

A usability overhaul of the university library's Online Public Access Catalog — the search, cataloging, and book reservation interface students use every day, previously slowed down by too many steps.

Audited the existing flow end to end, then redesigned it with accessibility as a first-class constraint so it reads clearly no matter how comfortable the user is with catalog software.
